### web 前端常用工具代码片段

学习 / 复用向的前端 snippets，已清理琐碎草稿与重复实现。

#### 目录说明

| 目录 | 内容 |
|------|------|
| `utils/` | 工具函数（防抖节流、密码校验、笛卡尔积、请求封装等） |
| `iview/` | Vue2 + iView 表格 / 表单封装 |
| `html/` | 可运行的页面示例（扫码、滑块、购物车等） |
| `observe/` | Proxy 响应式原理练习 |
| `calendar/` / `element/` | 日历组件（手写 / Element 插槽） |
| `node/` | Node 片段（JWT / COS STS / LDAP，依赖宿主项目的 settings） |
| `canvas/` / `video/` / `G6/` | Canvas、视频控件、流程图示例 |

#### 保留原则

- 有明确复用或学习价值的完整示例
- 同一能力只保留一份实现
